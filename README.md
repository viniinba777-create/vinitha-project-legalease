# ⚖️ LegalEase

## AI-Powered Legal Document Generator

LegalEase is an AI-powered application that helps users create legal document drafts using Google Gemini.

## Features

- Generate legal document drafts using AI
- Supports Rental Agreement
- Supports Leave/Application Letter
- Supports General Notice
- Supports Affidavit-style Draft
- Supports NDA
- Supports Employment Agreement
- Download generated documents as TXT files
- Simple Streamlit interface

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- python-dotenv

## Disclaimer

LegalEase generates AI-assisted document drafts for informational purposes. It is not a substitute for professional legal advice. Documents should be reviewed by an appropriate legal professional before use.
